# SAIT Futuristic Multi-page Redesign

A high-polish, static HTML/CSS/JavaScript prototype for the SAIT Website Redesign Challenge.

## Structure

- `index.html` — student-first homepage / landing experience
- `about.html` — department + SAIT story, vision, mission, faculty/admin model
- `people.html` — executive, faculty and student directory with filters
- `events.html` — filterable event archive + detail modals
- `placements.html` — careers and placement dashboard
- `alumni.html` — alumni spotlight
- `hall-of-fame.html` — achievements archive
- `activity.html` — working localStorage activity logger
- `notifications.html` — filterable announcements
- `notes.html` — academic resources
- `contact.html` — contact form, social links and map
- `data.js` — all sample data in one place
- `style.css` — shared responsive design system
- `script.js` — interactions, theme switch, command palette, rendering and local storage
- `assets/logo.svg` — SAIT-style prototype mark

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## GitHub Pages

Keep `index.html` at the root of the repository. Then enable:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Replace before submission

The challenge allows mock data and placeholder images. Before submitting a production-looking version:
1. Replace sample names, roles, metrics, events, alumni and achievements with official SAIT data where available.
2. Replace sample portrait photography with SAIT/CUSAT-approved images.
3. Replace the placeholder Instagram and GitHub links with official/current URLs.
4. Check every event registration link, recruiter name, placement number and contact detail.
5. Keep the "sample" labeling while mock content remains.
